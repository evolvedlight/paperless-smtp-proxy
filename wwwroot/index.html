2. DNS MX Record Configuration

                

                    To receive emails sent from any outside email provider (Gmail, Outlook, iCloud, etc.) to steve@paperless.brown.bg:
                

                
    
                    
  1. Add an A or CNAME record for paperless.brown.bg pointing to your home public IP or dynamic DNS hostname.
    2. 
                    
  2. Add an MX record for paperless.brown.bg pointing to paperless.brown.bg with Priority 10.
    3. 
                    
  3. Forward WAN Port 25 (TCP) on your home router to your NAS IP on port 25.
    4. 
                


                
3. Portainer / Docker Deployment

                

                    Deploy using the included docker-compose.yml in Portainer (Stacks → Add Stack). Make sure the container joins the same Docker network as Paperless to communicate directly via internal container name (e.g. http://paperless-web:8000).
